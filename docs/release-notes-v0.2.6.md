# Codex Quota Dot v0.2.6

- Added **Start at login** to the Windows system tray and macOS menu bar menu. It is off by default; enable it to show the quota orb automatically after signing in to your computer.
- Uncheck the option to disable automatic launch. The menu reads the OS registration and reports failures so you can retry.
- Windows startup supports executable paths containing spaces and Chinese characters. Keep portable copies in a permanent location before enabling this option.

---

- Windows 系统托盘和 macOS 菜单栏菜单新增 **开机自启动 / Start at login**。默认关闭，勾选后在登录电脑时自动显示悬浮球。
- 取消勾选即可关闭自启动。菜单读取系统启动项的实际状态，设置失败时会提示重试。
- Windows 自启动支持包含空格和中文的程序路径。便携版请先放在固定位置，再开启自启动。
